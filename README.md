# BIGVU Growth Audit

**Live → https://eddieatadapty.github.io/bigvu-flow-rebuild/**

Five ideas to turn more BIGVU users into subscribers, each built into a clickable version of BIGVU's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the four answers you already collect | +10–20% CR to purchase |
| 02 | Let them try the teleprompter before the price | +5–15% CR to purchase |
| 03 | Put AI Pro Yearly on the paywall | +10–15% ARPU (more annual plans) |
| 04 | Offer Starter to people who close it | +10–15% ARPU, from people who close it |
| 05 | Show proof from their own field | +5–10% CR to purchase |

Every price, rating and feature comes from BIGVU's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for BIGVU. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
